# 五大刊

JF / JFE / RFS / JFQA / RF 的阅读器：按期刊翻期、随机刷卡片、早报（Early View）。

手机请装 [Releases](https://github.com/linshp7-create/wudakan/releases) 里的 APK（应用名「五大刊」）。打开应用会从本仓库拉取最新目录；有新安装包时应用内会提示更新。

- **期刊**：选刊 → 选 2026 年某一期 → 一屏一篇往下刷
- **早报**：还没正式出刊的新文；进正式刊之后会出现在对应那一期，早报里不再显示
- **随机**：把已收录论文洗成一列竖滑
- 每张卡片可 **收藏**、**评论**（只存在手机本地，不上传）

数据文件：[`data/journal-data.json`](data/journal-data.json)

安装 APK 时如提示未知来源：设置 → 应用 → 特殊应用访问 → 安装未知应用，允许「五大刊」或你用来打开该文件的应用。
